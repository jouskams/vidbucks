# Licensing checklist
| item | rule |
|---|---|
| reference videos | analyse public metadata/captions and view in the browser; never download or re-upload someone else's video; a file the user supplies is the user's responsibility |
| images and footage | CC0 / public domain / CC BY / CC BY-SA / Pexels / Pixabay only, with credits; skip NC and ND; keep `credits.json` |
| people | no private people's faces, no celebrity or athlete likeness; use statues, busts, models, objects, silhouettes, procedural art |
| logos / brands | no third-party logos; the user's own brand is rebuilt as clean vectors |
| music | royalty-free or generated (`make_pulse_track.py`, `make_synth_library.py`); no copyrighted tracks |
| voices | each engine and each voice has its own licence (Piper voices vary; some are non-commercial); do not clone a real person's voice without their consent |
| Remotion | free for individuals and small teams under its own licence; larger companies need a company license - check https://www.remotion.dev/license |
