# Fidelity checklist (before delivering)
- [ ] Measured the reference (file or link + visual pass) and said what is unknown.
- [ ] Type and devices named; route chosen in one line.
- [ ] Assets licensed with credits recorded; no private people's faces, logos or copyrighted footage.
- [ ] Render measured: `--compare` table and `--sidebyside` image produced and LOOKED at.
- [ ] Captions never overlap; no text outside the frame; first 0.3 s not empty; last frame not abrupt.
- [ ] Loudness matches the reference (or -16 LUFS when unknown); true peak <= -1.5 dBTP.
- [ ] Every requested format rendered and checked (9:16, 16:9).
- [ ] Credit lines for CC BY assets prepared.
- [ ] Honest note: what was verified, what was not (audio was not heard), the one change that would help most.
