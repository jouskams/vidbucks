Use the `vidbucks-reference-to-video` skill with the reference and brief in $ARGUMENTS. If the reference is missing, ask for it (and for what the user wants to say); do not ask for anything else the skill can find itself. Follow the golden path: measure -> look -> classify -> plan -> collect assets -> build -> measure the result -> iterate (about 4 loops) -> deliver with the score table, side-by-side and credit lines.
